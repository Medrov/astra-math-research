# Проверенные связи из полиномиального шага §9.1

## Реальный поиск Astra: автоморфизм координатной алгебры

31 октября 2026 режим «Найти общую структуру» получил исходную теорему
`Arxiv261038474.subtract_restore` и весь неизменённый входной Lean-модуль.
Astra выбрала **MSC 13, 14 и 37** и предложила **пять кандидатов**. Поиск
потребовал 4 вызова и 251.578 секунды. Запросы, фактически найденные декларации,
профиль и кандидаты сохранены в [astra-discovery.json](astra-discovery.json).
Нижеописанный готовый контроль `prodShear` модели не передавался.

Выбран кандидат **«Контравариантная подстановка и упаковка обратимости»**.
Для `A = R[X₀,X₁,X₂]` и исходных полиномиальных троек `F=graphSubtract b w`,
`G=graphRestore b w` он утверждает существование

```text
α : A ≃ₐ[R] A
α(p)      = eval₂Hom C F p
α.symm(p) = eval₂Hom C G p
```

Утверждение верно для произвольного коммутативного кольца `R` и любых
`b,w : Polynomial R`. Доказательство использует **обе** исходные теоремы
`subtract_restore` и `restore_subtract`; выбранная теорема не является его
единственным входом. Линейность полиномиального преобразования на `R³`
и непрерывность не утверждаются.

Существующий процесс LangGraph разложил задачу на четыре обязательства:

1. Совпадение `MvPolynomial.aeval` с исходным `eval₂Hom C`.
2. Контравариантность композиции: `φ_K ∘ φ_H = φ_(compose H K)`.
3. Обе обратные композиции подстановочных гомоморфизмов.
4. Существование алгебраической эквивалентности с указанными формулами.

Первые попытки двух вспомогательных лемм получили ошибки Lean. Astra исправила
их по диагностике, сохранив контракт и определения. Все четыре обязательства,
финальная пересборка и аудит аксиом завершились успешно; смысловая рецензия
вернула `aligned`. Этап доказательства занял 6 вызовов и 429.390 секунды.
Использование исходной `subtract_restore` и всех четырёх релевантных исходных
определений подтверждено графом зависимостей из компилятора.

Материалы фактического запуска:

- [AstraCoordinateAutomorphism.lean](AstraCoordinateAutomorphism.lean) — неизменённый финальный код Astra.
- [AstraCoordinateAutomorphism.contract.json](AstraCoordinateAutomorphism.contract.json) — точные четыре цели.
- [astra-verification.json](astra-verification.json) и [журнал Lean](astra-verification.log) — реальные результаты, типы, хеши, зависимости и `#print axioms`.

Разрешённые аксиомы — только `propext`, `Classical.choice`, `Quot.sound`.
Этот результат подтверждает выбранную связь с координатной алгеброй. Кандидат
о спектре проверен следующим отдельным запуском, описанным ниже; ещё три
кандидата не проверены. Новизна и вся статья этим не удостоверяются.
Это повторное использование доступных исходных доказательств, не слепое переоткрытие.

Снимок поискового графа получил вторую версию только для сохранения точных
найденных библиотечных фрагментов после доработки контроллера. Исходные ответы
поиска, математические утверждения и выбранная теорема не менялись; факт
миграции сохранён в `astra-discovery.json`.

## Следующий кандидат MSC 14: гомеоморфизм спектра

31 октября 2026 Astra проверила исходный кандидат `route_2_bridge_spectrum`
через тот же процесс LangGraph: формализация, смысловая проверка контракта,
граф лемм, исправление по диагностике Lean, итоговая сборка, аудит и смысловая
проверка результата. Входной Lean-файл и условия кандидата не менялись.

Пусть `R` — любое коммутативное кольцо, `b,w ∈ R[t]`, `A=R[X₀,X₁,X₂]`.
Обозначим подстановку исходного `F=graphSubtract b w` через `αF`, а подстановку
его обратного `G=graphRestore b w` — через `αG`. Доказаны три обязательства:

1. `αG ∘ αF = id` и `αF ∘ αG = id`, с использованием обеих исходных теорем.
2. Для идеала оси `J=(X₁,X₂)` и идеала графа
   `IΓ=(X₀-b(X₁), X₂-w(X₁))` выполнено **`Ideal.map αF J = IΓ`**.
3. Существует `R`-алгебраический автоморфизм с прямым `αF` и обратным `αG`,
   а также **гомеоморфизм `h : Spec A ≃ₜ Spec A`** с топологией Зарисского,
   причём `h(𝔭)=αF⁻¹(𝔭)`, `h.symm(𝔭)=αG⁻¹(𝔭)` и **`h(V(IΓ))=V(J)`**.

Здесь `V(I)` — множество простых идеалов, содержащих `I`. Прообраз в формуле
для `h` — прообраз идеала по гомоморфизму; это объясняет направление переноса.
Доказательство работает со всеми простыми идеалами, а не только с `R`-точками.
Условий поля, алгебраической замкнутости или топологии на `R` нет.

Живой запуск `abf14508267f4c1a83e58b37d01e65dc` завершился `proved`:
**3/3 точных обязательства**, финальная сборка и аудит успешны, смысловая
проверка — `aligned`. Первая попытка вспомогательной обратимости не прошла;
Astra исправила её по диагностике. Остальные обязательства прошли с первой
попытки. Всего **5 вызовов Astra, 461.937 секунды**, при бюджете 16 вызовов /
1800 секунд. Seed App Server не предоставляет. Код вручную не исправлялся.
Отдельная рецензия агентом, не писавшим доказательство, смысловых ошибок не нашла.

## Подготовленный контроль: общая эквивалентность слоёв

Это **заранее подготовленный контроль**, а не результат живого запуска Astra
и не заявление о новом математическом открытии. В демонстрационном поиске
модель может получать исходную теорему и найденные библиотечные сведения;
готовый `Bridge.lean` не должен передаваться ей как якобы найденное доказательство.

Исходный результат — заключительный шаг §9.1 работы A. S. Frolov и
I. S. Dorofeev, [arXiv:2610.38474v1](https://arxiv.org/html/2610.38474v1#S9.SS1).
Для коммутативного кольца `K` и `b,w ∈ K[t]` преобразование

```text
S(x,y,z) = (y, x-b(y), z-w(y))
```

имеет полиномиальное обратное и переводит уже заданный граф `(b(t),t,w(t))`
в ось `(t,0,0)`. Исходные обе композиции и образ графа уже доказаны **как
равенства полиномов**, а не только значений на точках.

Вход [Arxiv261038474.lean](../../research_fixtures/Arxiv261038474.lean)
компилируется заново под именем `StructureInput`; namespace
`Arxiv261038474` сохраняется. Комментарий `atlas-structure-source-sha256`
в мосте фиксирует SHA-256 его текста UTF-8 с нормализованными переводами строк.

## Точный новый мост

Общий механизм — `fiberShear f (a,u) = (a,u-f(a))` на `A × B`, где
`A` — произвольный тип, `B` — аддитивная группа и `f : A → B` — любая функция.
Условий линейности или непрерывности для биекции нет. Она построена через
`Equiv.prodShear (Equiv.refl A) (fun a => Equiv.subRight (f a))`.

В частном случае берём `A=K`, `B=K×K`, `f(t)=(b(t),w(t))` и переставляем
исходные координаты: `(x,y,z) ↦ (y,(x,z))`. Теорема
`CommonStructure.graphSubtract_eq_prodShear` доказывает точное равенство
evaluation исходного `Arxiv261038474.graphSubtract` этой общей конструкции.
Это мост между **отображениями на точках**; он не подменяет исходные более
сильные полиномиальные тождества и не выводит их обратно из поточечного равенства.

[Bridge.lean](Bridge.lean) содержит шесть доказанных теорем:

| Декларация в `CommonStructure` | Проверенное утверждение |
|---|---|
| `fiberShear_apply` | Явная формула общего отображения |
| `fiberShear_inverse` | Обе обратные композиции общей эквивалентности |
| `fiberShear_graph` | Граф любой функции переходит в нулевое сечение |
| `graphSubtract_eq_prodShear` | Evaluation исходного полиномиального преобразования совпадает с `prodShear` после перестановки координат |
| `graphSubtract_graph_to_axis` | Частный граф полиномов переходит в ось на точках |
| `squareShear_not_additive` | При `f(t)=t²` над `ℚ` отображение не сохраняет сложение: свидетели `(1,0)+(1,0)` |

## Три направления дальнейшего поиска

MSC здесь обозначает предметные направления, а не формальное доказательство связи.
Имена ниже — воспроизводимые ориентиры для поиска и проверки источников;
приложение не должно подставлять их как готовый результат поиска.

| MSC | Общий механизм и необходимые условия | Библиотечные ориентиры и граница |
|---|---|---|
| **14R10**, автоморфизмы аффинного пространства; **13F20**, полиномиальные кольца | Полиномиальный профиль даёт треугольный полиномиальный автоморфизм после перестановки координат; исходные равенства верны над любым `CommRing K` | `Arxiv261038474.graphSubtract`, `subtract_restore`, `restore_subtract`, `graph_to_axis`; мост использует `eval_univariate`, `Equiv.prodShear`, `Equiv.subRight`. Это заключительный шаг, без построения предшествующего автоморфизма статьи |
| **54H11**, топологические группы; **54C05**, непрерывные отображения | Для топологической аддитивной группы `B` и непрерывной `f : A → B` обе формулы `(a,u) ↦ (a,u∓f(a))` непрерывны, что даёт гомеоморфизм произведений | `Homeomorph.shearAddRight` и `Homeomorph.shearAddRight_coe` — близкий библиотечный частный случай `(x,y) ↦ (x,x+y)`. Общая непрерывная версия для произвольной `f` здесь **не формализована**; одной `Equiv` непрерывность не доказана |
| **15A04**, линейные преобразования | На модулях линейная `f` даёт линейный сдвиг `(a,u) ↦ (a,u-f(a))`; нужны сохранение сложения и скалярного умножения. Произвольная полиномиальная `f` этих свойств не даёт | `LinearMap.prod`, `LinearMap.fst`, `LinearMap.snd`, `LinearEquiv.prodCongr` — строительные компоненты, не готовая теорема об этом сдвиге. Положительное линейное обобщение здесь не формализовано; отрицательный контроль над `ℚ` доказан |

Первичные библиотечные источники закреплены на mathlib
`c44e0c8ee63ca166450922a373c7409c5d26b00b`:
[Equiv.prodShear](https://github.com/leanprover-community/mathlib4/blob/c44e0c8ee63ca166450922a373c7409c5d26b00b/Mathlib/Logic/Equiv/Prod.lean#L298-L309),
[переводы аддитивной группы](https://github.com/leanprover-community/mathlib4/blob/c44e0c8ee63ca166450922a373c7409c5d26b00b/Mathlib/Algebra/Group/Units/Equiv.lean#L150-L157),
[топологический сдвиг](https://github.com/leanprover-community/mathlib4/blob/c44e0c8ee63ca166450922a373c7409c5d26b00b/Mathlib/Topology/Algebra/Group/Basic.lean#L554-L569),
[произведения линейных отображений](https://github.com/leanprover-community/mathlib4/blob/c44e0c8ee63ca166450922a373c7409c5d26b00b/Mathlib/LinearAlgebra/Prod.lean).
Названия `Equiv.subRight` и `Homeomorph.shearAddRight` создаются в этих исходниках
через `to_additive`; их наличие дополнительно проверено настоящим `#check`.
