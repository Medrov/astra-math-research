# Когда рост энергии треугольника строгий

В двух запусках через Astra App Server проверялись заранее зафиксированные формулировки о ребре 0–2 взвешенного треугольника. Оба файла содержат свои исходные определения и проверяются по отдельности.

| Гипотеза | Результат программы |
| --- | --- |
| Увеличение веса с `a` до `b` всегда строго увеличивает квадратичную форму. | При нулевых значениях на всех трёх вершинах обе формы равны нулю. Опровержение потребовало 2 вызова Astra. [Доказательство](Counterexample.lean) |
| Если `a < b` и значения `x₀` и `x₂` различны, увеличение строгое. | Разность форм равна `(b − a)(x₀ − x₂)² > 0`. Программа израсходовала 6 вызовов Astra. [Доказательство](StrictIncrease.lean) |

Чтобы повторить проверку, откройте вкладку «Программы SHAIM», выберите файл, укажите имя целевой теоремы и её ожидаемый Lean-тип из [сохранённого отчёта](../../checks/triangle-counterexample.json), затем нажмите «Проверить файл». Проектные определения и доказательства проверяются локальным Lean. Повтор не требует вызовов Astra.
