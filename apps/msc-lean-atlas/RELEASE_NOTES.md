# v0.3.0 — поиск общей структуры и проверяемые примеры

Релиз от 1 ноября 2026 года. Основной сценарий лаборатории:
**источник → переход статьи → аналоги в трёх других областях MSC →
точная постановка → Lean → результат и история**.

## Что доступно

- Карта MSC2020, карта объектов и переходов с номерами, формулами KaTeX,
  входами и выходами выбранного перехода и отдельным графом лемм.
- Astra через Codex App Server предлагает направления и кандидатов.
  LangGraph сохраняет этапы и контрольные точки. Граф обязательств и роли
  реализованы в этом проекте по мотивам Goedel-Architect.
- Навигация между этапами без повторного запуска; история исследований,
  журнал работы, повторная попытка и редактирование отклонённой постановки
  как новой версии. Последовательная проверка доступных кандидатов запускается
  после просмотра списка и общего бюджета.
- Предварительная проверка типов отделена от доказательства. Причины
  остановки — неверная постановка, отсутствие доказательства, ошибка Lean,
  бюджет или сбой сервиса — показываются отдельно. Ни один такой исход
  не объявляется доказательством отсутствия математической связи.

## Два готовых источника

| Источник | Что формализовано |
| --- | --- |
| Наш пример «Одна энергия в двух описаниях» из [препринта](../../docs/Preprint.pdf) | Рациональная трёхвершинная модель: энергия ассоциатора совпадает с квадратичной формой взвешенного лапласиана. Исходная теорема — `associatorDirichlet_graphLaplacian`, интерфейсный вход — `Bridge.energy_correspondence`. |
| А. С. Фролов, И. С. Дорофеев, [On the motivic approach to the Abhyankar rectifiability problem and concrete rectifications](https://arxiv.org/abs/2610.38474v1), §9.1 | Полиномиальные преобразования вычитания и восстановления графа взаимно обратны над коммутативным кольцом; граф переходит в координатную ось. Вход — `Arxiv261038474.subtract_restore`. |

Оба источника доступны в селекторе готовых примеров. При первом добавлении
компилируется выбранный источник; интерфейс может повторно открыть уже
сохранённый проверенный источник. Наш пример при проверке также пересобирает
закреплённые проектные зависимости. Это исключение доступно только для точного встроенного
примера; обычная загрузка Lean-файла сохраняет ограничение на импорты
Mathlib/Init/Std.

Для шага Фролова–Дорофеева сохранены результаты реального поиска Astra:
автоморфизм координатной алгебры и гомеоморфизм её спектра. Их код,
точные цели, происхождение и ограничения находятся в
[examples/common_structure](examples/common_structure/README.md).
Скрипт `tools/reproduce_common_structure.py` повторяет проверку без модели;
`--spectrum` выбирает спектр, `--control` — отдельно подготовленный контроль.

## Окружение и границы

Проверяемый локальный набор: Windows, Python 3.12.10, Node 24.15.0,
Lean 4.19.0 и mathlib `c44e0c8ee63ca166450922a373c7409c5d26b00b`.
Установка и запуск описаны в [README](README.md), состав публикации —
в [PUBLICATION.md](PUBLICATION.md). Для новых исследований нужна доступная
модель `gpt-6-astra` и авторизация Codex. Проверка сохранённых доказательств
не вызывает модель.

Это поиск по установленной библиотеке mathlib и локальному корпусу, с
импортом конкретной статьи arXiv по ссылке, а не обход всего arXiv.
MSC служит навигацией. Lean удостоверяет точную формальную цель и её
предпосылки; соответствие статье, полезность и новизна оцениваются отдельно.
Проверенный шаг §9.1 не является формализацией всей статьи, а гомеоморфизм
спектра не утверждает изоморфизм схем со структурным пучком.

Попытка по *When Momentum Helps Polyak–Ruppert Averaging*
([arXiv:2610.27990v2](https://arxiv.org/abs/2610.27990v2)) остановилась по
тайм-ауту Codex на поиске кандидатов: сохранённых кандидатов и результата
Lean нет. Она не включена в два проверенных примера.

Свежая проверка релиза зафиксирована в
[checks/release-0.3.0.json](checks/release-0.3.0.json).
Прошли 283 Python-теста и 197 записей JavaScript TAP без ошибок и пропусков
в проверенной локальной среде. Lean заново проверил три сохранённых моста,
второй готовый источник и исходный комплект из 11 файлов / 149 деклараций;
все команды завершились с кодом 0. В чистом клоне некоторые JavaScript-тесты
исторических локальных записей явно пропускаются. Вызовов Astra при выпуске нет.
Остальные датированные отчёты описывают предыдущие запуски. Локальные
`research_data/`, базы истории, полные тексты импортированных статей,
сессии Codex и персональные пути не входят в публикацию.
