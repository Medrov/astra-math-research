# Публикация лаборатории — 30 октября 2026

Опубликованы исходники приложения, полная выгрузка MSC2020 с атрибуцией,
готовые локальные графовые библиотеки, тесты, фиксированные Lean-примеры
и документация исследовательского этапа. Математические исходники перенесены
без изменений. Для переноса заменены машинные пути на настройки окружения,
а исторические сертификаты примера помещены в `checks/`.

Исходная рабочая папка SHAIM и её сервер продолжают существовать отдельно.
Эта папка — переносимая копия для Git. История запусков, SQLite-индекс,
Codex session IDs, виртуальное окружение, журналы попыток и исходные материалы
встреч не публикуются. Установите зависимости и соберите индекс по README.

`checks/` содержит выбранные фактические отчёты разработки. В JSON удалены
локальные пути и идентификаторы сессий Codex; поля типов, хешей доказательств,
результатов и времени сохранены. Это экспорт свидетельств, а не новый запуск
Lean. Ссылки на `verification/`, `runs/` и `research_data/` в исторических
документах относятся к исходной среде разработки и после клонирования отсутствуют.
Вместо локальных run-ссылок смотрите `checks/research-generalization-final.json`
и `examples/energy_kernel/Proof.lean`.

## Проверки

Перед публикацией на этой копии прошли 105 Python-тестов, 17 тестов графа
и 8 сценариев HTTP API. Три контрольных пилота и доказательство ядра энергии
заново проверены Lean: [результат](checks/publication-lean.json).
Свежие журналы: [Python](checks/publication-python-tests.log),
[HTTP API](checks/publication-api.json). Модельные вызовы при подготовке публикации
не выполнялись. Исходный пакет MathResearch не изменён; дополнительно проверено,
что его скрипт по-прежнему обнаруживает ровно свои 11 модулей и не включает
фикстуры приложения. Полная компиляция основного пакета заново не запускалась.

После установки `.venv` и подготовки Lean/mathlib:

```sh
.venv/bin/python -m unittest discover -s tests -v
npm run test:graph
```

Для пересборки frontend-зависимостей: `npm ci --ignore-scripts` и
`npm run build:graph-bundle`. Готовая сборка включена, поэтому запуск приложения
и тесты модели графа не требуют установки Node-пакетов.

Браузерным сценариям нужен Playwright (в разработке 1.62.1):
`npm install --no-save --package-lock=false playwright@1.62.1`,
`npx playwright install chromium`. Можно указать путь модуля через
`ATLAS_PLAYWRIGHT_MODULE`. Сценарий `verify_research_ui.cjs` требует уже выполненных
пилотов и одного успешного multi-запуска на тестируемом сервере; их отсутствие
не заменяется моками или вымышленными результатами. Проверка API
`python verify_research_api.py --base-url http://127.0.0.1:8765` запускает
только локальный отрицательный пилот. `evaluate_research.py` вызывает Astra.

Обобщение энергии графа в `examples/energy_kernel/Proof.lean` — результат
реального исследовательского запуска: энергия равна нулю тогда и только тогда,
когда значения совпадают на концах каждого ребра при строго положительных весах.
Это известная структура, новизна не заявлена. Файл проверяется Lean 4.19.0
в контексте закреплённой mathlib; сертификат и точный тип находятся в `checks/`.

Приложение требует локальный Python backend. GitHub Pages не запускает
исследовательские задачи, Codex или Lean.
