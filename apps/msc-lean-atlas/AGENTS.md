# Исследовательская лаборатория

Это самостоятельное локальное приложение внутри репозитория. Не изменяйте
исходный набор MathResearch ради тестов приложения: его 11/149 не включают
Lean-примеры этой папки.

- Запуск и переменные окружения описаны в README.md и PUBLICATION.md.
- Проверки: `python -m unittest discover -s tests -v`, `npm run test:graph`.
  Lean-тесты требуют подготовленного Lean 4.19.0 и mathlib; пропуски сообщайте явно.
- `research_data/`, `runs/`, `verification/`, `.venv/`, `node_modules/` остаются локальными.
- `checks/` — отобранные отчёты с удалёнными машинными путями. Исторический
  отчёт не считать свежим запуском. Сохраняйте типы, хеши и фактические результаты.
- Не запускайте платные исследования только ради публикации или обычного теста.
- Не возвращайте сравнение двух загруженных Lean-файлов в UI без запроса.
- Lean проверяет формальную цель; смысл, полезность и новизна оцениваются отдельно.
