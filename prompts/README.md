# Опорные промпты для трёх выполненных задач

Задания приведены в рабочей редакции: повторы устной речи убраны, входы и результаты обозначены явно. Это инструкции повторного запуска, а не буквальная стенограмма.

Начните с [пошагового примера](../WALKTHROUGH.md). Для проверки готовых Lean-файлов достаточно [REPRODUCE.md](../REPRODUCE.md).

| Когда использовать | Промпт | Результат |
| --- | --- | --- |
| Начало работы | [01-coordinator.md](01-coordinator.md) | План и распределение заданий |
| Разбор сужения поиска | [02-candidates.md](02-candidates.md) | Карточки трёх существующих задач |
| Проверка известности | [03-literature.md](03-literature.md) | Источники и сравнение формулировок |
| Первая ветвь | [04-geometry.md](04-geometry.md) | Ассоциатор, расстояния и восстановление |
| Вторая ветвь | [05-spectral.md](05-spectral.md) | Остаток и условия спектральной оценки |
| Третья ветвь | [06-incidence.md](06-incidence.md) | Каталог, поиск и проверка проб |
| Общие правила авторов | [07-lean.md](07-lean.md) | Проверка формализации и исправлений |
| После трёх ветвей | [08-review.md](08-review.md) | Замечания по смыслу и границам результата |
| После закрытия замечаний | [09-handoff.md](09-handoff.md) | Полная проверка и итоговый отчёт |

Сначала передайте координатору 01. Он назначает обзор и литературу, затем авторов 04–06 с правилами 07, после них рецензента 08. Сам координатор завершает работу по 09. Параллельность определяется возможностями среды; названия ролей не означают использование разных моделей.
